Fridgedoor

Privacy

Fridgedoor is software you run yourself. We, the people who make it, never receive your household's data.

Where your data lives

Everything (plans, lists, email-derived suggestions, account details) is stored in one database on the server your household runs. Sensitive fields are encrypted there. Whoever runs that server can access it; usually that's you.

What leaves your server

  • Your AI provider, the one your household picked, receives emails you've connected (one at a time, trimmed), what you send the planner, and summaries for the morning brief. Each provider has its own data policy.
  • Your email provider, which Fridgedoor reads from. It never sends, deletes or marks mail as read.
  • Google Calendar, only if you connect it.
  • Push notification services (Apple, Google, Mozilla) carry short notification text, if you turn notifications on.

The iPhone app

The app talks only to your household's server. It collects no analytics and contains no tracking or advertising code.

This website

fridgedoor.dev is a static page hosted on GitHub Pages, with no cookies or analytics. Pairing links keep the server address and code after the #, which browsers never send to the website.

The full technical details are in docs/privacy.md.
